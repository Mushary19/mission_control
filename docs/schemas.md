# Schemas

Generated by `scripts/gen_schemas.py` from the Pydantic models in [`backend/app/schemas/`](../backend/app/schemas/) with real examples from `out/` and the API (long lists cut to 2 items). Times: `*_local` = Sri Lanka time (UTC+05:30), `*_utc` = UTC.

Other `out/` files: `0_profile.json` (record counts, time formats and duplicates per person and source), `2_screen_summary.json` (context / noise / out-of-scope screen sessions per mailbox, title and day), `pipeline_report.json` (counts per stage and phase summaries).

## Pipeline: event (`out/1_events.jsonl`, `out/2_events_clean.jsonl`)

One row per deduplicated record or screen session. Keys that are null or empty are left out of the files. `text` is cut to 200 characters; `/api/events/{id}/raw` returns the full original line(s).

| field | type | required | description |
|---|---|---|---|
| `event_id` | `str` | yes | "<source>:<native id>"; screen sessions use "screen:<mailbox>:<first line>" |
| `source` | `Literal['mail', 'calendar', 'teams_chat', 'teams_channel', 'screen']` | yes |  |
| `mailbox` | `str` | yes |  |
| `seen_in` | `list[str]` | no |  |
| `time_utc` | `str` | yes |  |
| `time_local` | `str` | yes | Asia/Colombo (UTC+05:30) |
| `actor_id` | `str | None` | no |  |
| `recipients` | `list[str]` | no |  |
| `title` | `str | None` | no |  |
| `text` | `str | None` | no | Plain text, cut to 200 chars; the full record is served by /api/events/{id}/raw |
| `text_truncated` | `bool` | no |  |
| `category` | `Optional[Literal['process', 'context', 'noise', 'out_of_scope']]` | no |  |
| `noise_reason` | `str | None` | no |  |
| `activity` | `str | None` | no |  |
| `process` | `Optional[Literal['leave', 'offboarding', 'onboarding']]` | no |  |
| `subject_person_id` | `str | None` | no |  |
| `resolution` | `Resolution | None` | no |  |
| `fields` | `dict[str, Any]` | no |  |
| `thread_key` | `str | None` | no |  |
| `raw_ref` | `RawRef` | yes |  |
| `session` | `Session | None` | no |  |
| `meta` | `dict[str, Any]` | no |  |

## Pipeline: screen session (inside an event)

Frames of one window (same mailbox + title, gaps <= 10 min).

| field | type | required | description |
|---|---|---|---|
| `start_local` | `str` | yes |  |
| `end_local` | `str` | yes |  |
| `start_utc` | `str` | yes |  |
| `end_utc` | `str` | yes |  |
| `frame_count` | `int` | yes |  |
| `minutes` | `float` | yes |  |

Example:

```json
{
  "end_local": "2026-03-02T10:01:53+05:30",
  "end_utc": "2026-03-02T04:31:53Z",
  "frame_count": 2,
  "minutes": 9.9,
  "start_local": "2026-03-02T09:51:56+05:30",
  "start_utc": "2026-03-02T04:21:56Z"
}
```
